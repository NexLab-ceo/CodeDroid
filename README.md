# CodeDroid — Native Kotlin Android IDE

Нативный Android-прототип IDE на Kotlin и Jetpack Compose. Ветка `kotlin-native` сохраняет прежний веб-прототип в `main` и содержит отдельную реализацию для Android.

## Реализовано

- Нативный интерфейс Jetpack Compose, адаптирующийся к планшету и телефону.
- Редактируемый Kotlin-код и локальное сохранение черновика.
- AI-чат через OpenAI-compatible endpoint.
- Режимы Local / Cloud / Auto и настройки URL/модели.
- Настройки сохраняются локально на устройстве.

## Сборка

Открой проект в Android Studio, выбери JDK 17 и дождись Gradle Sync. Затем запусти конфигурацию `app` на Android-устройстве или эмуляторе.

После установки Gradle Wrapper можно собрать APK командой:

```bash
./gradlew assembleDebug
```

APK будет находиться в `app/build/outputs/apk/debug/app-debug.apk`.

## Подключение AI

В настройках приложения укажи URL OpenAI-compatible `/v1/chat/completions` для локальной модели. Для режима Cloud укажи URL совместимого chat-completions сервера. Для Ollama на компьютере и приложения на физическом планшете укажи LAN IP компьютера вместо `10.0.2.2` (этот адрес работает в Android Emulator).

Не встраивай секретный API-ключ в APK. Для облачных провайдеров используй backend-прокси с ключом на сервере.
