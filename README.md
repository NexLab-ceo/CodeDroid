# CodeDroid / CodePilot AI

Адаптивный прототип IDE для Android-планшетов: редактор CodeMirror, дерево файлов и чат AI с режимами Local / Cloud / Auto.

## Статус
Это ранний веб-прототип, а не нативное Android-приложение. Файлы пока хранятся в `localStorage`, а встроенная консоль демонстрационная и не запускает команды ОС.

## Запуск
Требуется Node.js 18+.

```bash
npm install
cp .env.example .env
npm run dev
```

Для backend/облачного AI см. `README.md` в исходном архиве. Не коммитьте API-ключи или `.env`.
